# 第12ラウンド提出: 住まいクラスタの「興味本位レイヤー」設計（発想B）

冒頭に**Orbの教訓の自己適用**を記します。R11で私は「常時観測型の消費者製品は未発見」と書きましたが、Orb（2025年4月、Ookla創業者Doug Suttlesによる常時ネット品質監視・無料・全プラットフォーム、確認日2026-08-29）を見落としていました。原因は検索語彙が日本語＋「doctor」系に偏り「internet quality monitor」を引かなかったこと。よって**第3サイクル（建物回線モジュール）の差別化は「観測エンジン」ではなく「物件紐付け×日本の集合住宅/ISP事情×管理会社向け成果物」に置き直します**。観測エンジンでOrbと競わない。本ラウンドの全空白主張は、この教訓に従い敵対的検索済みです。

## 1. 現象の実在検証: 「住宅データの眺め見」は実在する行動か

**結論: 実在する。しかも4つの好奇心型すべてに、現役の実例と数字がある。**（全確認日2026-08-29）

| 実例 | 検証結果 | 駆動する好奇心の型 |
|---|---|---|
| Zillow surfing（米） | 利用者の83%が購入意図ゼロで物件閲覧（Omnis調査）、米成人の35%が「funのため」にZillowを見る（CivicScience）、68%が「セラピー的」、44%が週次習慣 | 妄想/憧れ＋覗き見 |
| 大島てる（日） | 投稿10万件超、2005年から20年存続、TV番組「てる散歩」化＝引越しと無関係の娯楽的閲覧の証拠 | 怖いもの見たさ |
| 間取り図鑑賞文化（日） | 「間取り図大好き！」コミュニティ最大19万人、イベント「間取り図ナイト」、書籍『間取りと妄想』、madree掲載2,427件。「住む気がない物件の間取り図が楽しい」という当事者言説を確認 | 妄想（日本固有の強い文化） |
| 東京R不動産（日） | 物件を「読み物」に編集し7,000件超の成約へ接続——眺め見→取引ファネルが商売として成立した国内先例 | 憧れ/編集的好奇心 |
| みんそく（日） | 4年で385万→累計700万測定超。測定という自分の行為と他人との比較が閲覧動機 | 自分ごと比較 |
| HowMa（日） | 売る気がなくてもメール登録だけで自宅のAI査定額を見られ、マネーフォワードME連携で資産価値の定点観測として日常化 | 自分ごと比較（自己資産の値動き） |
| SoundPrint（米） | 飲食店の騒音をユーザーが15秒測定で投稿、16万ユーザー・14都市超のQuiet List——「測る好奇心」がデータ供給になる実証 | 自分ごと比較＋市民科学的貢献感 |

**設計上の最重要発見**: 4つの型のうち、**閲覧がデータ供給を生むのは「②自分ごと比較（自分の家を測る）」だけ**。①覗き見・③怖いもの見たさ・④妄想は消費専用。よって②を供給エンジン、③④を流入装置と役割分担し、①（他人の住戸の覗き見）はプライバシー逆風なので採らない。

## 2. 設計案（4案）

### 案C1「わが家の偏差値」— 10分の自宅測定で全国分布の中の自分を見る【本命】
- 内容: 自宅で騒音（昼/夜dB）・4キャリア電波・回線実測・照度を10分で測るガイド付きキット→「あなたの家は静けさ偏差値61／電波偏差値43」カードを生成、SNS共有
- 好奇心型: ②自分ごと比較（共有カードが①覗き見の流入も生む）
- 初日から成立するか: 段階設計。騒音は環境省の常時監視点＋道路距離モデル、電波はキャリア公表エリアで粗い全国推定分布を初日から提供し、「全国◯件の実測中の順位」表示は実測蓄積後に解禁と明示（推定と実測をUI上で峻別——これを崩すとブランドが死ぬ）
- 資産・ファネル接続: 自宅測定は内見と同一の測定キットの練習であり、比較の基準線になる。内見本体の主機能を「この物件はあなたの家より夜間+4dB／電波1段階弱い」という自宅比表示にすることで、興味本位層の測定が本体機能の精度を直接上げる。供給母数は引越し層→全世帯へ
- 敵対的検索: 「自宅 住環境 診断 偏差値 全国 比較」→MatchTowns（街マッチング診断）、ホームインスペクション（プロの人力）、うちエコ診断のみで、環境実測の全国比較ツールは不在を確認。騒音計アプリは多数あるが全て単体メーターでマップ・分布機能なし

### 案C2「よるの静けさマップ」— 実測騒音の眺め見ヒートマップ
- 好奇心型: ③怖いもの見たさ＋④妄想
- 初日から成立: 不成立（密度ゼロで地図は成立しない）。「この駅の夜間実測はまだ2件——あなたの10秒測定で解禁」という解禁ゲートを付け、眺め見客を供給者に変換する設計でのみ出す（SoundPrintのチャレンジ企画が同構造で機能）
- 敵対的検索: 「騒音 マップ アプリ クラウドソース 日本」→地図型・共有型は不在を確認。SoundPrintは飲食店特化で住宅・街区はカバー外

### 案C3「駅の実測番付」— 実測で駅を並べる年次メディア
- 好奇心型: ④妄想＋②
- 初日から成立するが4案中最もv3臭が強い→初版から「実測が推定を上書きしていく」進行表示と駅単位の解禁ゲートを義務化
- 敵対的検索: 大東建託「住みここち」は20万人アンケートの主観満足度、SUUMO住みたい街は人気投票。客観実測の駅ランキングは不在を確認。同時に住みここちの毎年報道は「駅ランキングは年次メディアイベントとして引用される」経路の実証

### 案C4「妄想内見レポート」— 住む気のない物件も1タップで「住んだら報告書」
- 好奇心型: ④妄想（19万人コミュニティで実証済み）
- 公開データ+推定で初日成立。全数値に「推定」バッジ、実測が存在する建物は「実測あり」で上書き
- 資産・ファネル接続: 妄想レポートと本番の内見ログが同一様式なので、ユーザーは遊びながら本体の使い方を学習済みになる（東京R不動産型の遅効変換）
- 敵対的検索: SUUMOの通勤時間検索・HowMa等のAI査定（価格のみ）はあるが、環境実測×様式化レポートは未発見

## 3. v3再演回避の条件（自問込み）

「資産に興味本位を足せばv3と違う」は自動では成立しない。成立条件は1つだけ: **興味本位面が資産を太らせるか**。製品規律:
1. 供給変換の義務: 全ての眺め見ビューに測定への変換装置（解禁ゲート・自宅比較・実測バッジ）を組み込む。変換装置のない純閲覧機能は作らない
2. KPI: DAUや滞在時間ではなく「訪問あたり測定提出数」と「引越し期に本体へ復帰した率」。6ヶ月で転換が立たなければ③④型ビューは畳む
3. 土俵の限定: 物件リスティングの眺め見はSUUMO/LIFULLの完成した土俵なのでやらない。眺め見は他社が持たない実測レイヤーの上でのみ
4. コスト規律: 興味本位面は資産の別ビューとして作り、専用データ収集はしない

## 4. 「自宅測定」派生の評価

先例4つで実証済みの型: みんそく（自宅測定が供給エンジンで700万件）、Opensignal（日常の受動測定→200万人超の貢献者→通信事業者へのデータライセンス企業化）、HowMa（売る気のない自宅査定→定点観測化）、Orb（自宅常時観測を無料配布してデータ企業化を狙う現在進行形）。母数は引越し層・年数百万人→全世帯約5,000万超に広がり、頻度問題も緩和され、内見比較の基準線としてデータ供給が桁増。

緊張関係（正直な評価）: (i)表面が「診断おもちゃ」化して内見ツールの立ち位置がぼやける (ii)自宅と内見は測定条件が違うため分布を無造作に混ぜると比較信頼性が壊れる (iii)ソロの開発リソース分散。緩和設計: 自宅測定を独立機能にせず「内見比較の較正ステップ」と定義／測定文脈タグ（自宅・内見・屋外）でスキーマ分離／出荷順序は内見コア→自宅基準線→眺め見ギャラリー。

**総括**: 本命はC1（4案中唯一、初日から部分成立し、供給ループを内蔵し、空白が確認でき、本体機能を直接強化）。次点はC4。C2・C3は解禁ゲート付き流入装置として従属（転換率が立たなければ畳む）。
