## 1. 結論

**構想のままの形——「世界中の物件を、写真付きで、自分のマップに載せる」——は実現できない。** 障壁は技術ではなく、データの入手経路と写真の権利である。

**ただし成立する形が2つある。** どちらも「世界中」を諦め、「写真の権利チェーンがきれいな供給源」に限定することで立つ。

---

## 2. なぜ実現できないか

### 2-1. ポータルのAPIは全部「逆向き」だった（本調査で最も重要な発見）

Rightmove、OnTheMarket、ImmoScout24、Immobiliare.it、Kyero、Green-Acres、thinkSPAIN、HousingAnywhere、Domain Listings Management——これらの「API」はすべて **業者が物件をアップロードする入口（inbound）** であって、第三者がデータを取得する出口ではない。`developers.○○.com` の存在を「公開APIがある」と読むのは誤読になる。

### 2-2. 米国MLS/IDXは完全に閉じている

NAR方針によりMLS参加は有効なブローカー免許保有者に限定。決定打は運用ルールで、**データライセンスを持つベンダーですら、自社のための一般公開の物件閲覧サイトを作れない**。Bridge / MLS Grid / Trestle / SimplyRETS はすべてこの制約の下流にあり、迂回路はない。

### 2-3. 写真は独立した地雷

- VHT v. Zillow: 約$2M確定
- CoStar v. Zillow: 2025年7月提訴、53,000枚、$10億超の可能性
- **Zillowですら写真で2回やられている**
- Datafinitiは自社規約で画像の公開表示を禁止（＝売り手自身が「使うな」と言っている）

### 2-4. スクレイピングは選択肢にならない

- hiQ v. LinkedInは「勝った」わけではない。CFAAは回避したが2022年12月に**$500,000の判決＋恒久差止で会社が消滅**
- EUは Ryanair v. PR Aviation により**契約でスクレイピングを禁止でき、それが有効**。米国のロジックが通らない
- idealistaは利用規約で明示禁止＋DataDome WAFで技術的にも最難関クラス

### 2-5. 写真なしなら合法な選択肢は複数あるが、要件を満たさない

RentCast（$0〜）、PropertyData（£28/月〜）、Homedata（無料枠）、URA API、不動産情報ライブラリ——いずれも写真を伴わない。要件が「押すと室内写真が見られる」である以上、全て失格。

**政府オープンデータで写真付きの募集中物件を出している国は、見つからなかった。** Overture/OSMにも物件リスティングは含まれない。

## 3. 成立する2つの形

### 形A: 欧州の国際向けエージェントから直接XMLフィードを受ける【本命】

- **Kyero XML** が国際エージェント間の事実上の標準フォーマットとして存在し、公開仕様がある
- エージェント側は既にこのフィードURLを持っているため、「URLを貼るだけ・掲載無料」なら供給が来る
- **写真の権利チェーンが唯一クリーン**（エージェント自身が配信を意図している）
- Kyero / Green-Acres / thinkSPAIN 自身が通った実証済みの道
- コスト構造: **エンジニアリング1週間、営業6ヶ月**。鶏卵問題（トラフィックが先か在庫が先か）が最大の関門

### 形B: 豪州 Domain API【条件付き】

- 世界で唯一、APIキーがセルフサーブで取れる（500 calls/day、images フィールドあり）
- **ただし T&C が「Approved Purposeに指定された態様でのみ表示可」と定め、Domainは「競合製品を作りうる」と明示留保**。消費者向けポータルとしての用途承認は通らない可能性が高い
- 参考: Booking.com Demand API は「画像URLをimgタグで使用可、ファイルDLは不可」と**写真許諾が明文化されている唯一のセルフサーブAPI**だが、不動産ではなく宿泊

## 4. 日本法の重要な発見（構想の順序を決める）

宅建業法の「宅地」は**日本国内所在物件と解され、海外物件を含まない**（RETIO・高川佳子弁護士2018）。したがって:

- **海外物件のみを扱う限り、宅建業免許は原則不要**
- **国内物件に触れた瞬間に媒介該当リスクが立つ**

この非対称性が「まず海外から始める」という順序を裏づける。ただし国交省自身が「今後の検討課題」としており、収益化時は弁護士確認が必須。

補足: A8.net / バリューコマース等に**不動産の物件データフィードは存在しない**（案件はリードジェン広告のみ）。ECの商品データフィードとの混同に注意。

## 6. 本当の空白 — 「住む場所を決めるデータ」と「実際の物件」の分断

**これが唯一、敵対的検索で空白が確認できた導線である。**

分断の「自白」証拠:
- **WhereNext は公式に「実際の物件は idealista / DDProperty / 99.co で見よ」と外部誘導している**
- Nomad List・Numbeo・Global Property Guide は、いずれも物件を持たない
- 逆に Properstar・Rentola・Kyero は、気候・ビザ・時差・ネット速度を検索軸に持たない

ただし純粋な空白ではなく、物件側から接近中の先行者がいる:
- **Flatio**（全リースがビザ用住所証明）
- **TripOffice**（デスク保証・100カ国20万件）

### 埋まっている導線（敵対的検索で確認済み・作らないこと）
自然言語検索（Properstar 2026実装、Zillow/Redfin/Realtor.comのChatGPTアプリ）／isochrone通勤検索（Zoopla・FoxtonsがTravelTime導入済み）／価格履歴（idealistaは査定乖離まで表示）／AI室内写真加工（REimagineHome等レッドオーシャン）／新着即時通知（Rightmove日70万通知＋差分を売るDwellioが既存）／日照シミュレーション（PLATEAU使用の無料サービス既存）／**日本のakiya（空き家）**（AkiyaMart/AkiyaHub/AkiyaJapan/AllAkiyas/CheapHousesJapan等10社超で飽和）

### 次点の空白: グローバル「眺め見」エンタメ導線
フォロワー0・予算0という制約と唯一相性が良い。実証: Zillow Gone Wild（430万フォロワー・HGTV番組化）、1eurohouses.com（地図でCNN/NYT/BBC報道を獲得）。ただし Cheap Old Houses が既に "Abroad" 派生を持つ。

## 7. 技術とコスト — 全部解ける

| 構成（100万件・月300万セッション） | 月額 |
|---|---|
| **推奨: MapLibre + Protomaps PMTiles on R2 + R2画像** | **$340 ≈ ¥54,000** |
| 地図を Mapbox に置換 | $9,476 ≈ ¥151万 |
| 地図を Google Maps に置換 | $21,256 ≈ ¥339万 |

**62倍の差**。地図が主UIのサービスは1セッション=1 map loadなので、Google/Mapboxは検討に値しない。

### 規模別の月額（キャッシュ配信）
- 1万件 / 月3万セッション: **$22.6（¥3,612）**
- 10万件 / 月30万セッション: **$132（¥21,090）**
- 100万件 / 月300万セッション: **$340（¥54,266）**

### 推奨アーキテクチャ
- **最小構成（月$17〜19 ≈ ¥3,000）**: Hetzner CAX21 1台にPostgres+PostGIS+pgvector+Meilisearch+imgproxy同居、地図は **OpenFreeMap公開インスタンス（完全無料・無制限・APIキー不要）**、画像はR2+CF CDN（egress $0）。→ 10万件快適/30万件上限、月5〜10万セッション
- **成長構成（月$333 ≈ ¥53,000）**: AX41-NVMe + CAX31×2、Protomaps PMTiles on R2、LocationIQ $49。→ 100万件快適/300万件上限

### AIコストは正しく設計すれば最小項目
10万物件の初回処理（Batch API・画像縮小・8枚束ね）: Gemini 2.5 Flash-Lite で画像解析$49 + 10言語翻訳$85 = **$135**。Claude Haiku 4.5なら$1,541、Opus 5なら$7,700。**LLM翻訳はGoogle Translate API（$16,000）の100〜190倍安い**。Embeddingは10万件で$1.20（一度きり）。

### MVP工数
1カ国・1万件・地図＋写真＋検索で **385時間 ≈ 週20時間で19週（約4.5ヶ月）**。AI支援はフロントエンド・CRUD・スキーマで35〜45%効くが、フィードの癖・重複排除のしきい値調整・タイル性能チューニングにはほぼ効かない（0〜15%）。

### 技術的な致命リスク
1. **Google Geocodingの緯度経度は最大30日でキャッシュ削除義務**（永続保存可はplace_idのみ）→ 物件DBの座標として規約上使えない。フィード内蔵lat/lon優先＋LocationIQ（$49/月で月30万件）
2. **Cloudflareは無料CDNでの画像偏重配信を禁止**（Service-Specific Terms）→ R2等の有料サービス必須
3. **TypesenseはCJKで詰む** → Meilisearch（charabia）を選ぶこと。なお言語横断検索（日本語で検索→英語物件にヒット）はBM25では原理的に不可能
4. フィルタ付きタイルのキャッシュキー爆発 → 属性4〜6個をタイルに焼き込みクライアント側フィルタで解く
5. 重複排除の残り10〜20% → 画像pHashを最初から入れる
6. Hetznerが2026年6月にCCX/CPXを113〜175%値上げ（ARM系は+30%で最小）／**Gemini 2.5 Flash-Liteが2026年10月16日提供終了**（最安試算の前提モデル）

## 8. 収益モデル（実在確認済み）

- 海外不動産 **CPL $1.82〜$25**（英語ドバイ/ギリシャ $2.48〜4.34、露語トルコ $7.05〜17.49）、SQL適正 $30〜60
- **Green-Acresは顧客の1/3に嫌われてリード課金を捨てた**実証あり
- 掲載課金: Kyero Prime €3〜6/物件/月、Rightmove Overseas 個人 £130/月、Flatio 家主5〜7.5%、Blueground 7%
- アフィリエイト: SafetyWing 10%×12ヶ月（≒$50/人）
- **ソロの実証例: Cheap Houses Japan が $10/月ニュースレターで月$8,000**（Starter Story）

### 個人が取れるモデルの序列
1. 有料ニュースレター
2. アフィリエイト
3. データ/API販売（Numbeoが$50〜500/月で実証）
4. Kyero型フリーミアム掲載
5. リード課金（月$3,000に月120〜1,500リードが必要）
- **論外: Rentola型の借主サブスク**（Trustpilot 1.9〜2.2、解約困難の告発多数）

## 10. 三系統の調査が独立に到達した同一の結論
